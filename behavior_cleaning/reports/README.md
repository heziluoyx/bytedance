# 项目分析报告

本目录保存按用户批注更新的三份报告，数据期均为2025年11月18日至12月18日。原始行为表、数据库和用户级预测明细不随报告上传。

- [特征有效性评估报告](特征有效性评估报告.docx)：相关性热力图、互信息、验证集置换重要性和概率校准。评估目标是用户未来7天任意商品购买，不是用户—商品对购买模型；已删除批注指定内容及完整30项排序表。
- [探索性数据分析报告](探索性数据分析报告.docx)：保留12幅核心图表，补充双十二节点日活对比，解释类目编号、小时顺序和用户分群，删除批注指定段落。
- [核心数据洞察总结](核心数据洞察总结.docx)：按批注精简，并写入重新执行SQLite得到的浏览、加购、收藏购买路径与运营建议。

完整7天观察期中，浏览后购买38,094／3,567,270对，加购后购买17,667／215,401对，收藏后购买5,804／176,095对，分别约1.07%、8.20%、3.30%。起点均为窗口内首次观测行为，各路径可以重叠；同小时无法判断先后。购买标记不等于已核验支付订单，各比例不能解释为营销增量。

复核代码见 [analyze_purchase_paths.py](../scripts/analyze_purchase_paths.py)，口径说明见 [purchase_path_analysis.md](../docs/purchase_path_analysis.md)。汇总JSON、CSV归档在 `evidence/`，可与代码输出核对；不包含用户或商品明细。
