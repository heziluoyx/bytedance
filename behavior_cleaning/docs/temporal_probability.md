# 严格时间窗口购买概率预测

目标为用户商品对未来7天出现购买行为的条件概率。输出0到1连续概率，真实目标仍为0/1，采用分类概率损失训练而非连续金额回归。用户购买任意商品是不同目标，本版本不把两者混用。

## 时间设计

现有31天数据不足以提供7天历史加四个独立7天标签窗口。本轮统一历史3天，未来目标7天，弃用随机7:2:1。

| 阶段 | 历史范围 | 未来标签范围 |
| --- | --- | --- |
| 训练 | 11月18日至20日 | 11月21日至27日 |
| 参数验证 | 11月25日至27日 | 11月28日至12月4日 |
| 融合与校准 | 12月2日至4日 | 12月5日至11日 |
| 最终测试 | 12月9日至11日 | 12月12日至18日 |

所有日期为2025年，区间按当天00时起、下一天00时前处理。融合与校准窗口再按用户稳定哈希二分，用户组互斥，不根据购买标签划分。跨日期用户/商品允许重复，同一快照用户商品对唯一。真实零历史对象不在最近交互候选中，训练未见对象只是冷启动代理。

每窗口从历史候选按稳定标识哈希抽取最多80,000对，不使用未来标签平衡测试集。时间划分保留自然分布差异，不人为保证购买率一致。目标编码5折、填补、标准化和商品词表均只在训练阶段拟合。

## 模型与校准

逻辑回归、XGBoost、LightGBM各比较四种不平衡方案，再在参数验证窗口按AUC调优。LSTM、GRU、DIN和多头注意力DIN分别对比两组配置，使用验证AUC早停及学习率衰减。历史最多16个活跃小时、每小时最多4件商品池化，不还原小时内事件先后。

Stacking在后续融合组拟合逻辑回归、XGBoost及DIN的logit输出，属于时间留出式Stacking，不是训练内时间多折OOF。全部基模型只拟合最早训练窗口，验证期选择参数，融合期也不重新拟合基模型。

自然分布校准组为各模型拟合Platt逻辑校准，辅助分类阈值也在该组确定。主评估为AUC、AP、Brier、Log Loss、ECE和校准曲线；准确率、召回率、F1只作为辅助。校准拟合内效果不代表泛化，后续校准器对早期样本的回放概率不可冒充当时已可用的预测。

## 促销影响

武汉市商务局转载报道记载2025年12月3日活动启动。训练标签在此之前，验证窗跨启动，后两个窗覆盖活动，日期仅用于事后评估背景，未将事后新闻作为当时模型输入。早期窗口不被认定完全无其他促销；缺活动曝光字段，不能识别因果影响。

最后7天为严格参数隔离的测试，仍可能因购买率漂移导致概率失准，不根据该测试再次校准。本次没有足够常态与活动后独立窗口，不能推断全年泛化。源清洗阈值曾参考全期，本轮仍有清洗回看限制。

## 运行

使用现有项目Python环境，另需torch、scikit-learn、imbalanced-learn、xgboost、lightgbm、optuna、duckdb、pyarrow、pandas、numpy、matplotlib、scipy和joblib。训练已使用CPU两线程完成，环境版本与旧模型相同；新机器请优先独立虚拟环境复现这些版本。

```powershell
python behavior_cleaning/scripts/train_temporal_probability.py
```

可用 `--stage dataset` 只构建样本，`--stage report` 只重建已有结果的报告。`--source` 指定清洗后Parquet；`--output-dir` 指定新输出；`--max-pairs`、`--trials`、`--epochs`、`--deep-configurations` 控制预算。已完成结果禁止覆盖，不同配置必须新建目录。

默认输出 `outputs/temporal_probability_20261109`，包含样本、编码、八种模型和校准器、连续概率、重要性与SHAP、分组误差、业务模拟及三份HTML/Markdown报告。只有SUCCESS代表全部步骤完成。所有用户标识和预测明细仅存本地。

XGBoost使用原生TreeSHAP，DIN使用六组完整穷举Shapley，经校准斜率变换后解释校准logit；不把注意力权重当SHAP，不当作因果贡献。A/B分组和收入仅为模拟，无真实投放，所有业务增量与金额参数须经真实随机实验验证。
