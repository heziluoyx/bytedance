# 双十二窗口敏感性与传统模型重训

原12月12日单截点随机划分不能代表所有经营时期。公开活动介绍及武汉市商务局转载报道均记载2025年12月3日启动年终狂欢季，因此原用户级12月5日至11日与12月12日至18日标签周也不是明确的常态对促销对照。

本轮不把日期邻近直接当作活动因果效应，而是重新训练用户商品对任务的三种传统模型，单独报告较早留出和后期压力测试。

## 实际设计

- 开发截点2025年11月25日00时；历史为11月18日至24日，标签为11月25日至12月1日。
- 较早120,000个用户商品对内分层7:2:1，种子42：训练84,000对204正例，验证24,000对58正例，留出12,000对29正例。
- 后期压力截点2025年12月12日00时；历史为12月5日至11日，标签为12月12日至18日，120,000对772正例。
- 两期全部累计特征统一7天。候选和抽样只由历史资格决定；编码、填补、缩放只在较早训练集拟合。
- LR、XGBoost、LightGBM分别比较四种不平衡策略，并各执行12次Optuna试验；策略、参数和阈值在较早验证集确定后冻结。
- 较早集合内部仍为随机划分，不伪称完全时间隔离；较早开发与后期压力集的标签窗口分开，后期样本不参与此次调参。

## 结果

| 模型 | 较早留出AUC | 后期压力AUC | 后期AP | 后期召回率 | 后期F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 逻辑回归 | 0.8509 | 0.8967 | 0.0996 | 0.1697 | 0.1708 |
| XGBoost | 0.8469 | 0.8933 | 0.1306 | 0.2500 | 0.2137 |
| LightGBM | 0.8485 | 0.8780 | 0.1055 | 0.2267 | 0.1942 |

较早留出正例仅29个，不能据微小分差判断稳定优胜模型。后期正例比例与购买行为规模均不同，AP、阈值指标和AUC需结合窗口解释。本次同时改变开发截点和历史长度，不能把旧模型与新模型的差异全部归因于促销。

## 运行与产物

安装与分析环境兼容的传统模型依赖，然后在仓库根目录运行：

```powershell
python -m pip install -r behavior_cleaning/requirements-models.txt
python behavior_cleaning/scripts/review_promotion_models.py
```

默认输出 `behavior_cleaning/outputs/promotion_review_20261104`；可设置 `--output-dir`、`--database`、`--max-pairs` 和 `--trials`。完整执行使用新的输出目录，避免把部分旧试验和新配置混用。已完成快照可在配置一致时复用，训练完成不再覆盖。

产物包含两个原始快照、较早样本划分、输入矩阵、预处理参数、三种模型权重、Optuna数据库及试验CSV、冻结配置、分窗口指标及本地预测、每日分布、特征PSI和中文HTML/Markdown报告。明细、标识和逐行预测仅保存在本地。

## 限制

数据只有2025年11月18日至12月18日，没有活动后完整回落期，也不足以在12月3日前构造三个独立的7日历史加7日标签窗口。较早标签窗口不能被认证为完全无其他活动或预热。

本轮沿用既有清洗结果，异常阈值曾参考全期分布，未声称清洗到模型全流程完全无回看。没有活动参与和曝光标记，不能识别促销因果增量；缺有效支付和退款，目标仍为购买行为标记。旧12月12日数据已在项目查看，本次只是未用于此次选择超参，不能称为首次未接触测试。

原用户级预评估属于不同目标和划分。本次仅包含三种传统模型，不混用两种目标的分数。
