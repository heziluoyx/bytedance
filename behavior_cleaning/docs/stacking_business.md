# 模型融合、可解释性及业务模拟

本阶段使用已完成的用户—商品未来七天购买训练产物，新增三折Stacking、逻辑回归系数、XGBoost TreeSHAP、DIN分组SHAP、误判和分群诊断，以及用户级模拟实验和收益情景。

## 运行

在仓库根目录运行，依赖沿用 `requirements-modeling.txt`，不需要额外安装SHAP库：

```powershell
python behavior_cleaning/scripts/analyze_stacking_business.py
```

默认读取 `behavior_cleaning/outputs/purchase_models_20261102`，输出至 `behavior_cleaning/outputs/purchase_followup_20261102`。`--run-dir`、`--output-dir`和`--database`可以分别指定训练产物、输出目录和只读SQLite。可以使用 `--stage stacking`、`--stage analysis` 分两步运行。

三折重训只使用原训练集；数值填补、缩放和类目有监督目标编码在每折重新拟合，商品和类目词表固定为原训练期无监督词表。DIN按原验证结果确定的6轮固定重训，不依据当前OOF留出折挑选轮数。基础模型各重训3次，二层为固定C=1的逻辑回归，使用OOF概率的logit及其训练拟合标准化。推断复用原完整训练集基模型。

完成的Stacking会复用检查点。源数据、基模型和实验配置保存SHA256指纹；源产物变化后必须使用新输出目录，不能将旧折预测与新数据混用。请勿同时启动两个进程写同一输出目录。分析阶段可以复用解释结果并重新生成报告，不再调优融合模型。

## 已运行结果与边界

本轮Stacking验证AUC为0.9417，测试AUC为0.9133、AP为0.1125、F1为0.1600，未超过XGBoost测试AUC0.9201和LightGBM0.9222。按用户成簇的500次配对bootstrap提供探索性区间；没有根据测试表现继续调参。

本轮测试集在上一阶段已经查看过，因此是同一留出集的扩展分析，不是全新未接触测试集的验证。三折是按用户商品对随机分层，同一用户可以跨折；不是完整冷启动或时间外评估，也不是嵌套交叉验证。原清洗阈值曾参考全期分布，正式端到端回测仍需按历史拟合清洗参数。

逻辑回归解释变换后标准化特征的系数。XGBoost采用原生 `pred_contribs=True, approx_contribs=False`，输出原始margin空间的精确TreeSHAP。DIN把全部输入划成六组，对128条随机测试样本枚举64个联盟，以8条训练样本作为经验背景，按Shapley公式计算logit贡献，并检查贡献加和。DIN解释是分组输入贡献，不是逐个原始特征或嵌入坐标的SHAP；混合背景可能违反实际联合分布，不能作因果解释。前后4条背景的敏感性结果一并输出。

未见用户是未出现在监督训练样本中的用户，本轮没有真正零历史用户。长尾定义为训练候选去重商品的历史交互量25%分位及以下，本轮阈值2次。固定阈值下长尾7个正例均漏报；未见用户组只有1个正例，不能据高AUC断言其泛化优秀。均值、中位数和案例只用于错误诊断，不将未观测到购买归因为具体交易阻力。

## 业务模拟口径

以用户稳定哈希1:1分组，验证集确定触达资格评分阈值；主分析限定实验前满足资格的人群，按初始分组ITT分析，不按实验后的打开或点击筛选。当前只是历史安慰剂模拟，没有真实触达，没有估计因果提升。

用户级基线从SQLite完整标签窗口的任意商品购买记录获取，不能用0.64%的候选对购买率替代用户转化率。缺订单、金额和退款时，购买行为率也不是支付率。样本量采用双侧5%、功效80%的两比例正态近似，14天招募+7天观察最早21天读主指标；若订单需30天退款成熟，最晚51天读净收益。

收益函数 `revenue_scenarios` 的人数、覆盖、客单价、毛利、退款均是显式假设。默认1万人、触达20%、150元客单、25%优惠前毛利、10%退款；假设转化绝对提升0.5/1/2个百分点。无券推荐和发券营销分别测算，补贴成本包括自然购买人群，并输出盈亏平衡提升。结果不能称为已实现收入、利润或线上A/B收益。

## 输出

- 根目录：两份中文HTML/Markdown报告与 `plots/` 下10张图。
- `stacking/`：二层模型、三折模型与预处理、OOF预测、验证及测试预测、冻结配置、模型比较CSV、源文件指纹。
- `interpretability/`：逻辑回归系数、XGBoost与DIN重要性CSV、逐样本SHAP和加和校验。
- `diagnostics/`：分群指标、混淆数量、错误特征画像、用户成簇AUC区间、固定候选预算命中率与本地误判案例。
- `business/`：历史分组平衡、合格用户平衡、样本量规划、假设收益、用户分组及推荐名单。

用户标识、商品标识、逐行预测和误判案例仅供本地分析。源代码可上传，公开仓库只保留不包含用户明细的报告及汇总。
