# 购买概率模型补充诊断

四份Word报告基于严格时间窗口预测结果，并补充排序、漂移、融合和SHAP诊断。基础模型保持冻结。这里的补充比较是在已有测试结果被查看之后执行，结果用于发现问题和制定下一轮方案，不是新的独立确认试验。

## 运行

在仓库根目录，先安装 `behavior_cleaning/requirements-probability.txt`，使用自己的清洗后Parquet完成时间窗口训练。源数据、样本、权重、用户标识和逐行概率不在Git仓库中。

```powershell
python behavior_cleaning/scripts/train_temporal_probability.py --source "清洗后Parquet路径"
python behavior_cleaning/scripts/analyze_probability_diagnostics.py --run-dir behavior_cleaning/outputs/temporal_probability_20261109
```

补充入口依赖已有 `dataset`、`models`、`all_window_predictions.parquet` 和 `interpretability`，不重新训练基础模型。结果写入指定运行目录的 `report_diagnostics/`，包括 `supplement/evidence.json`、本地补充概率和12幅新增图；固定文件名会覆盖同目录上一次补充诊断结果，原训练产物不变。不会自动改写Word报告。

## 指标口径

- AP汇总PR曲线，区别于梯形积分PR-AUC。概率指标以最终自然分布的80,000对、923个购买正例计算。
- NDCG、HR、MAP按用户内候选排序，再按用户等权平均，k取5、10、20。主均值只含753名抽样候选内有正例的用户，另记录全体7,421用户的HR；并列按固定输入顺序打破。MAP分母为min（正例数，k）。候选中位数只有6个，结果不能外推全量召回。
- 十分位Lift为各分组真实购买率除以总体购买率；前10%是8,000个用户商品对，不是8,000名用户。它不是营销因果增量。
- 得分PSI使用验证期原始分数固定十分位边界，特征PSI用训练期预处理值边界；合并并列边界、空箱以10⁻⁶平滑。标签另按0和1两箱计算。PSI低不代表促销期概率可靠。
- 本机CPU两线程、2,048对批次、预热1次再测7次的耗时只覆盖模型内核及序列模型现有张量组装，不是线上请求延迟或QPS；不包含召回、特征读取、网络、并发等。

## 补充融合

基础输入为LR、XGBoost和DIN的已校准概率。等权和加权软投票直接使用同尺度概率；权重以融合组AP在66个步长0.1的组合中搜索，得到0、0.7、0.3。概率Blending用融合组min-max和C=0.3的LR；去掉任一输入后重新拟合同样二层模型与校准器。硬投票按各自冻结阈值产生票数，再校准。路由按用户3天历史交互≥5条选择XGB/DIN各半，否则选择LR。

基础概率校准和融合后再校准复用同一校准组，不能把该组当独立性能证据。最终测试标签不用于拟合或选权重，但补充方案的比较已经接触最终测试，因此选型必须另取新窗口验证。历史logit Stacking作为独立实现保留，不谎称为概率输入，也不谎称训练内时间OOF。

## SHAP和业务边界

XGBoost沿用2,000条随机测试解释样本，并计算原生精确TreeSHAP交互；验证期另抽2,000条比较重要性。DIN沿用96样本、8背景的六组穷举Shapley。融合层图只解释第二层模型输入，不是原始字段的端到端SHAP。所有贡献单位为校准后的logit，不是概率百分点，也不是因果效应。

现有数据没有价格、优惠、真实曝光、渠道、支付金额或退款。报告中对此类分析标明缺失，不补造结果。训练未见用户不等于零历史新客；源清洗阈值曾参考全时段，仍有回看限制。A/B分组仅模拟，收益为明确参数下的情景测算。
