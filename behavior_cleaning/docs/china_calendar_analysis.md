重新运行仅日历分析，无需重做SVD或全部清洗：

```powershell
cd D:\字节\behavior_cleaning
python scripts\analyze_china_calendar.py
```

也可用`--database`指定新版数据库、`--output`指定尚不存在的输出目录。此入口只支持已核验的2025年；其他年份必须增加对应年度官方安排，不得直接复用日期。

输出文件：

- `china_mainland_calendar_2025.csv`：全年日历，可以作为其他分析的日历输入；
- `holiday_analysis.sqlite`：独立分析库，包含`dim_calendar`、`daily_behavior`及三张结果表；
- `calendar_daily_analysis.csv`：31天的日历关联明细；
- `holiday_comparison.csv`：假期0天、非假期31天，假期组统计为空；
- `workday_restday_comparison.csv`：考虑调休安排后的工作日/休息日比较；
- `calendar_analysis_summary.json`及`分析结论.md`：数据范围、口径和不可估计原因。

后续要估计假期差异，需要补充覆盖假期及前后普通日期的行为记录。例如补充2025年10月1日至8日国庆中秋假期及前后数据；多个假期与较长基线更便于排除星期、趋势和促销活动混杂。
